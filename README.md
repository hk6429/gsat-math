# 學測數學考古題

免費、免註冊的大學學測數學科互動題庫。網站以大考中心正式試題、答案、非選擇題評分原則與統計資料為唯一資料來源。

## 目前收錄

- 115 學年度數學 A：20 題
- 115 學年度數學 B：20 題
- 第 1～18 題均已逐題比對官方答案
- 第 1～18 題均收錄官方答對率／得分率（P）與鑑別度（D）
- 第 19、20 題為非選擇題，連結大考中心正式評分原則

目前題面採官方原卷精準裁圖，優先確保根號、矩陣、圖表、上下標與選填格式完全忠於原卷；後續版本再補可搜尋的結構化數學文字。

## 主要功能

- 數學 A／數學 B 切換
- 依單元、題型與難度篩選
- 單選、多選、選填題即時判定
- 官方 P、D 統計資料
- 查題校對頁
- 作答紀錄保存在使用者自己的瀏覽器

## 本機執行

```sh
npm run serve
```

## 驗證

```sh
npm test
```

重新由官方 PDF 產生 115 學年度逐題裁圖：

```sh
npm run crop:115
```

原始 PDF 預期放在 `.sources/115/`，該目錄不納入版本控制；正式來源與 SHA-256 記錄於 `sources/115.json`。

## 資料原則

- 題目與選項順序照官方原卷，不調動、不改寫。
- 答案逐題對照大考中心正式答案表。
- P、D 只採大考中心工作報告，查不到就省略，不推估。
- 非選擇題不做機器自動給分，避免把「答案」簡化成單一數字而忽略推理過程。
