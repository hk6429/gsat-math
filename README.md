## 主要功能

- 數學 A／數學 B 切換
- 依單元、題型與難度篩選
- 單選、多選、選填題即時判定
- 官方 P、D 統計資料
- 107～115 學年度官方各選項畫記率，並整合至逐選項文字解析
- 107～115 學年度逐題文字解析與 LaTeX／KaTeX 公式
- 查題校對頁
- 作答紀錄保存在使用者自己的瀏覽器

## 本機執行

```sh
npm run serve
```

## 驗證

```sh
npm test
```

建立完整發布包（含題庫、結構化題目與 KaTeX 靜態資源）：

```sh
npm run build
```

重新由官方 PDF 產生 115 學年度逐題裁圖：

```sh
npm run crop:115
```

83～115 學年度皆可使用 `npm run crop:<year>` 重新產生該年度題圖，例如 `npm run crop:83` 或 `npm run crop:115`。每年資料來源檔放在 `data/years/qXXX.js`，執行 `npm run build:bank` 會重新產生網站使用的 `data/bank.js`。

原始 PDF 預期放在 `.sources/{year}/`，該目錄不納入版本控制；正式來源與 SHA-256 記錄於 `sources/{year}.json`。

逐份核對已下載正式來源的 SHA-256：

```sh
npm run verify:sources
```

## 資料原則

- 題目與選項順序照官方原卷，不調動、不改寫。
- 結構化題面未經逐題核對前不標記為完成，網站會繼續顯示官方題圖。
- 答案逐題對照大考中心正式答案表。
- P、D 與各選項畫記率只採大考中心工作報告或官方統計表，查不到就省略，不推估。
- 非選擇題不做機器自動給分，避免把「答案」簡化成單一數字而忽略推理過程。
