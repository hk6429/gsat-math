## 主要功能

- 數學 A／數學 B 切換
- 依單元、題型與難度篩選
- 單選、多選、選填題即時判定
- 官方 P、D 統計資料
- 查題校對頁
- 作答紀錄保存在使用者自己的瀏覽器

```sh
npm run verify:sources
```

## 資料原則

- 題目與選項順序照官方原卷，不調動、不改寫。
- 答案逐題對照大考中心正式答案表。
- P、D 只採大考中心工作報告或官方統計表，查不到就省略，不推估。
- 非選擇題不做機器自動給分，避免把「答案」簡化成單一數字而忽略推理過程。
